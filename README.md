# Pallet Bid Lab — compare robotic palletizer quotes

A free, early-access browser demo for buyers comparing the scope of robotic palletizing proposals. Enter the details yourself and see where supplier offers differ before a purchasing decision.

**[Try the free interactive demo](https://woldemor31-byte.github.io/pallet-bid-lab-demo/)**

## What the demo does

- Compare up to three supplier proposals side by side.
- Record included and excluded scope for robot, gripper, guarding, installation, FAT/SAT and other cell elements.
- Add your own allowances for excluded work and flag unanswered items.
- Save a JSON backup, open a saved file, or print the comparison.

Use **Load example** to explore illustrative figures. Entries are stored in the browser on the current device; use the save function for a backup and avoid confidential data on shared computers.
